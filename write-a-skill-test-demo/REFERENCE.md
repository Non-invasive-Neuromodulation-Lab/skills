# Reference

## Input normalization

- Remove duplicate bullets.
- Normalize inconsistent section titles.
- Preserve semantic version and release date.

## Classification rules

- Added: new capability users can access.
- Changed: behavior updates to existing capability.
- Fixed: bug correction with user-visible impact.
- Deprecated: still works but planned removal.
- Removed: no longer available.
- Security: vulnerability or hardening changes.

## Quality checks

- Keep output under 250 words unless user asks for detail.
- Do not invent metrics, dates, or issue IDs.
- If source is ambiguous, flag uncertainty in Risks.
