# Abstract Template

## Usage
Use this template when writing the English abstract for an academic paper. All evaluated and generated text is English-only.

---

## Abstract

### [Paper Title in Title Case]

| Check | Status |
|-------|:------:|
| Covers all 5 components (Background, Purpose, Method, Findings, Implications) | ☐ |
| Within word count range (150-300 words) | ☐ |
| Grounded in the draft (no invented findings) | ☐ |
| Quantitative data consistent with the draft | ☐ |
| 5-7 keywords provided | ☐ |

| No citations in the abstract | ☐ |

---

## Guidelines

### Grounding Test
The abstract is truly grounded if:
- Every stated finding appears in the draft's results/discussion
- No claims are stronger than what the draft supports (protected hedges preserved)
- The abstract stands alone as a complete summary

### Keywords Strategy
- Keywords should complement (not duplicate) the title
- Mix broad discipline terms with specific research terms
- Include methodology terms if distinctive
